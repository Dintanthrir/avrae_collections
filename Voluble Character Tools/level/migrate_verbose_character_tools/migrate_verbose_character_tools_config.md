Converts a Verbose Characters Tools configuration gvar for use with Voluble Character Tools

```
!level migrate_verbose_character_tools_config <gvar_id>
```

- Converts classes and subclasses, hit dice, and custom counters.
- Converted classes still need a `sub_level` to specify when their subclasses become available.
- Consider adding features and automations to your converted (sub)classes.
- Many classes and subclasses already exist! Check the collection's page on the dashboard for a list of existing gvars and save yourself the trouble.
